# Atom State And Platform Boundaries (Effect 3)

Q51 uses @effect-atom/atom 0.6.0, @effect/experimental 0.60.0 and @effect/rpc 0.75.0, compatible with the locked Effect 3/platform versions. No React atom adapter or client rendering is qualified here.

- `no-effect-sync-console`: five direct, regular-callback, unused-nested and multiple-console cases. One report per outer sync, recursively including unused code. Effect logging routes through an actual pinned logger and retains 42. Alias/computed/named callbacks and import order are gaps; direct console output outside sync is outside this rule.
- `no-atom-registry-effect-sync`: twelve cases cover get/set/update/modify/refresh for actual registry and Atom calls, unused nested functions and first-match granularity. Registry actions are deferred closures; do not eagerly move mutation out of sync at module construction. Atom operations already return Effects: wrapping constructs an inner Effect but does not execute it. The repaired native Effect must run with real registry provision. This deliberately fixes missing execution rather than claiming the original nested Effect was executed. Alias/computed/named callback and import-order gaps remain. Only literal Atom/atomRegistry receiver names are recognised.
- `no-family-collection-read`: six actual family definitions cover CollectionAtom/ListAtom/Visible...Atom/ResultsAtom/ReadStateAtom suffixes, get/get.get/Atom.get and first-match recursion. The extra ordinary no-import case proves there is no ecosystem gate or binding ownership. Keyed source atoms retain present/missing projections and mounted updates. Renaming a broad collection, changing the receiver or using computed family access is a detector gap, not a repair. No general performance or React subscription guarantee is claimed.

`atoms.contracts.ts` checks actual lazy mutation, get/update/modify results, inner Effect construction versus execution, logger routing and mounted projection updates. All registries are disposed and mounts released. Anti-patterns remain intentionally unfixed.
